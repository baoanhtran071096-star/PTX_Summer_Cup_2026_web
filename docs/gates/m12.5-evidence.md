## 2. Real bugs found and fixed during M12.5 (not merely "checks passed")

M12.5 is not a re-labeling exercise — running the actual infrastructure found **four genuine, previously-undetected defects**, none catchable by M12's code-review-only process:

1. **Missing base Postgres GRANTs** on every table — RLS policies were correct, but `anon`/`authenticated`/`service_role` had zero table-level privileges, which Postgres denies before RLS is even evaluated. Would have blocked all data access, including `service_role` despite `BYPASSRLS=true`, in any real deployment. Fixed: `supabase/migrations/20260804000010_grant_table_privileges.sql`.
2. **Missing Auth→profile trigger** — no `public.profiles` row was ever created on Supabase Auth signup, so `getCurrentProfile()` returned `null` forever for any real user, making the entire M02 Auth+RBAC flow unusable end-to-end. Fixed: `supabase/migrations/20260804000011_auto_create_profile_on_signup.sql`.
3. **Next.js image optimizer SSRF guard blocking all local Storage images** — every avatar/logo returned `400 "url" parameter is not allowed` regardless of `remotePatterns` config, because Next's optimizer separately rejects any upstream URL resolving to a private IP (`127.0.0.1`, how local Supabase Storage is served). Fixed with a dev-only `images.unoptimized` toggle in `next.config.ts`, scoped to when `NEXT_PUBLIC_SUPABASE_URL` points at `127.0.0.1` — production keeps full image optimization.
4. **WCAG AA contrast failure on Team X's OVR badge** — `#f5a623` (Xiphias orange) text on a white card measures 2.02:1, found by running axe against a real-data page (`/doi`) for the first time. Fixed with a new `--text-on-team-x` semantic token (following the exact pattern M12 already established), with a dark-theme override since the raw color already passes there.

All four were verified fixed live (not just by inspection): re-running the exact failing request/scan/render after each fix.
